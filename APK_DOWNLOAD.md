# Where To Download The APK

After GitHub Actions succeeds, the APK is an artifact attached to the workflow run.

Steps:

1. Open the GitHub repository.
2. Click `Actions`.
3. Open the latest `Android Debug APK` run.
4. Scroll to the bottom of the page.
5. Download `jianhu-call-debug-apk` from `Artifacts`.
6. Unzip it.
7. Install `jianhu-call-debug.apk` on your Android phone.

The APK is not committed to the repository and will not appear in the code file list.
